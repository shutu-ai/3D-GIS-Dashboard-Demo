## Defect

ADM1/ADM2 overview labels rendered as **dark halo-ink ghost outlines** on dark
hypsometric terrain: the `text-halo-color rgba(16,22,30,0.85)` painted, but the
`#f2e9d4` fill interior collapsed below the SDF shader paint threshold.

Root cause: the bundled `public/assets/glyphs/Noto Sans Regular/0-255.pbf`
(generated by `scripts/pipeline/glyphs.py`) encodes its signed distance field
with **edge = 128** (128 = glyph outline, ±spread scaled to 1..255). MapLibre's
symbol SDF shader (maplibre-gl 5.24, `text-halo` gamma 0.75 math) expects the
convention produced by its own glyph generator **TinySDF 2.1.0**, whose default
`cutoff: 0.25` puts the outline at **edge ≈ 191.25**. With edge-128 bytes, the
fill interior distances land far below the effective paint threshold at
overview sizes (32px-em glyphs vs the engine's 24px assumption,
fontScale ≈ 0.44), while the halo band (a wider SDF iso-contour) still paints.

Byte forensics (`.data/font-fill-probe/RCA-summary.md`): edge mismatch,
stroke-core alphas 150–159, eq255=0, global max 223. Render forensics: no
structural fill failure — const-byte probes paint (a 128-byte glyph paints
120px), so the mechanism is a threshold/coverage collapse, not a parse defect.

## Initial implemented minimal fix (B-line; four-layer historical scope)

1. **`scripts/prepare_admin_font.py`** — deterministic stdlib builder. Verifies
   pinned input SHA `a658f4ca95dbdaa9d54bc10a9bde07cfcb6a42317bcf55bdd1e8e46a4be59715`
   BEFORE deriving, transforms ONLY glyph bitmap bytes
   `v' = clamp(round(191.25 + (v-128)*255/127), 0, 255)` (bytes outside the ink
   map to 0 by the formula itself), renames the fontstack alias to
   `Offline Admin Latin`, preserves ids/metrics/protobuf encodings byte-for-byte.
   Output: `public/assets/glyphs/Offline Admin Latin/0-255.pbf`
   SHA-256 `2ee61f0000cfc63ca24462aa08c599a8f512b968d24bfc78c797288e6edede3b`
   (417018 bytes; +2 = the longer alias only). No outlines regenerated, no
   metric mutations, no new deps, no new ranges.
2. **`scripts/validate_admin_font.py`** — strict standalone validator. ALL PASS:
   baseline bytes unchanged; 224 glyph ids; metrics identical; only bitmap diff
   and every byte equals the exact LUT; rebuild byte-identical (idempotent);
   bitmap payloads **byte-identical to the probe-validated diagnostic twin**;
   bitmap visual sheet `Docs/v1_2_1_admin_font_sheet.png`. NOTICE with OFL 1.1
   retention + MapLibre 5.24 / TinySDF 2.1.0 citations:
   `public/assets/glyphs/Offline Admin Latin/NOTICE.md`.
3. **`src/map/geographic-context.ts`** — `ADMIN_FONT_STACK = "Offline Admin
   Latin"` used by `admLabel` ONLY (the 4 layers `geo-admin-gb1-labels`,
   `geo-admin-gb1-labels-a`, `geo-admin-gb2-labels`, `geo-admin-gb2-labels-a`).
   All other layers keep `FONT_STACK` (old Noto bytes untouched). Styles
   unchanged (fill `#f2e9d4`, halo 1.2 — B passed with original styles).
4. **Priority reorder** — label ladder now low→high: localO/localD →
   townO/townD → ADM2O/ADM2A → ADM1O/ADM1A → majorO/majorD → peaks, so BOTH
   major layers outrank ALL ADM names at every active zoom (previously majorO
   sat before the atlas ADM pair, inverting 9.5..12.5 against the comment).
   Windows/seams, toggle groups, dimming, casing order
   (countryC→country→disputedC→disputed) and the `行政区 ADM2` copy untouched.
5. **`public/data/metadata.json`** — new independent key
   `geo_context.administrative_label_font` (sibling of
   `administrative_context`): fontstack, paths, input/output SHAs, size, glyph
   count, used_by_layers (exactly the 4 layers), transform formula, rationale,
   NOTICE/license pointers. No contract fields touched.
