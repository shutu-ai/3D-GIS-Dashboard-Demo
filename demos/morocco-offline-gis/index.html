数据来源 / Data Sources

REAL·OSM 地图底图、道路、水系与城镇地名来自真实 OSM/Protomaps 离线快照；地形为真实 DEM（Copernicus GLO-30），等高线由同一 DEM 生成。

行政边界：ADM1/ADM2 来自 geoBoundaries gbOpen（2017 · 9469f09），争议边界沿用 OSM 争议标记虚线显示。

要素优先级 / Feature Priority

SIM 「演示道路 / 参考地点」包含人工整理要素：道路为模拟几何（非真实 OSM，simulated:true），使用琥珀虚线，区别于真实道路的浅色实线；地点可为近似位置。山峰/隘口标注为公布标称海拔，不等于点击查询的原始 DEM 像元值。

同名去重：保留已整理参考点的名称与标称海拔，对应的真实地名标签不重复标注；不将两种来源合并为同一数据。RAN 覆盖始终为模拟演示（SIMULATED），切换 GIS/RAN 不改变本优先级。
