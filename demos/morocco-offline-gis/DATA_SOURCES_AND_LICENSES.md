# Data Sources & Licenses

## Summary

**All runtime data in this demo is programmatically generated (SIMULATED).**
No geographic, network, or cartographic data was downloaded from any external
source. This page documents exactly what each artifact is, where it comes
from, and under which license it ships.

## Terrain (DEM, contours, hypsometric tint) — SIMULATED

| Item | Value |
|---|---|
| Character | **Synthetic analytic elevation model** (user decision: fully programmatic) |
| Generator | `scripts/pipeline/dem.py` — ridged Perlin fBm + road-valley carving + anchor correction field |
| Anchors | Named real features pinned at their real coordinates and approximate real elevations (Toubkal 4167 m, Tizi n'Tichka 2260 m, …) so the demo looks plausible |
| Coverage | lon −8.4…−6.95, lat 30.85…31.55 (High Atlas, Morocco) |
| Encoding | Terrarium PNG tiles inside PMTiles v3 (z7–z12, 512 px) |
| Vertical datum | none — synthetic surface |
| License | Generated by this repository's own code; no third-party rights involved |

The one honest mapping to reality is *where* things are (coordinates of named
peaks/passes) and *roughly how tall* they are. Everything else — ridges,
valleys, slopes, the exact elevation of any pixel — is invented. Every UI
surface and this repository label it **SIMULATED**.

**REAL_DEM: NO** — if a real elevation source (e.g. Copernicus GLO-30) is
dropped in later, only `scripts/prepare_data.py`'s tile builder needs to
change; the data contract (`metadata.json`, tile encodings) stays identical.

## Contour lines — SIMULATED (derived from the same synthetic model)

Marching squares over the same analytic function as the DEM tiles, emitted as
MVT `contour` layers (`ele`, `major` attributes) in PMTiles v3, z6–z12,
interval 500 m (z6–8) / 100 m (z9–11) / 50 m (z12). Because DEM and contours
sample one function, they are mutually consistent by construction.

## Roads / peaks / places (`roads-peaks.geojson`) — SIMULATED

Hand-authored polylines and points derived from the anchor table in
`scripts/pipeline/dem.py`. Names refer to real places; geometries and
elevations come from the synthetic model.

## RAN overlay (`simulated-ran.geojson`) — SIMULATED

Nine invented sites (`GTW-*`), invented sector azimuths/heights/bands, and an
RSRP value per road segment computed from a toy distance+terrain-shadow
model. **No operator data, no real measurements.** Labeled
“SIMULATED NETWORK DATA” whenever displayed.

## Fonts — Noto Sans (SIL Open Font License 1.1)

- Source package: `@expo-google-fonts/noto-sans` (npm), file
  `400Regular/NotoSans_400Regular.ttf`
- License: SIL Open Font License 1.1 — permits bundling, redistribution and
  conversion. A copy is preserved at `.data/fonts/LICENSE-noto-sans.txt` and
  in the upstream npm package.
- The `.pbf` glyph ranges under `public/assets/glyphs/` are generated from
  that TTF by `scripts/pipeline/glyphs.py` (rasterized coverage bitmaps).

## Runtime network behaviour

The packaged app performs **zero external requests**: tiles, glyphs, GeoJSON
and metadata all load from the same origin served by `start-offline.ps1`
(127.0.0.1). Playwright acceptance tests assert this (`external requests must
be zero`).
